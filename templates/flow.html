URL Guardian

How URL Guardian Works

A comprehensive security analysis system powered by Machine Learning and AI

1. URL Input & Preprocessing

  • User enters URL for analysis
  • System validates URL format
  • Normalizes URL structure
  • Handles various URL formats (with/without protocol)

2. Machine Learning Analysis

  • Extracts URL features
  • Processes through ML model
  • Analyzes URL patterns and characteristics
  • Generates initial security assessment

3. WHOIS Data Analysis

  • Fetches domain registration data
  • Verifies domain age and ownership
  • Checks registration status
  • Analyzes domain history

4. Content Analysis with AI

  • Scrapes website content
  • Processes content with BeautifulSoup
  • Analyzes with Gemma AI
  • Generates comprehensive insights

5. Final Results

  • Combines all analysis results
  • Presents security assessment
  • Shows detailed domain information
  • Provides AI-powered insights

Technical Components

Machine Learning Model

  • TensorFlow/Keras implementation
  • 16 feature extraction points
  • Binary classification
  • Confidence scoring system

API Integration

  • WHOIS XML API
  • Groq API for Gemma model
  • BeautifulSoup for scraping
  • Async request handling

Frontend Technologies

  • Alpine.js for interactivity
  • Tailwind CSS for styling
  • Responsive design
  • Dark/Light theme support
